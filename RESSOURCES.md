# Ressources externes

Dépôts GitHub utiles pour tenir les politiques de confidentialité justes et les pages propres.

| Dépôt | À quoi il sert ici |
| --- | --- |
| [public-apis/public-apis](https://github.com/public-apis/public-apis) | Catalogue d'API gratuites. Quand une application ajoute une API, sa fiche dans ce catalogue donne le service, son authentification et le lien vers sa documentation, d'où l'on retrouve la politique de confidentialité du fournisseur à citer dans la page de l'application. |
| [validator/validator](https://github.com/validator/validator) | Validateur HTML du W3C (Nu Html Checker) : contrôler chaque page avant publication. |
| [GoogleChrome/lighthouse](https://github.com/GoogleChrome/lighthouse) | Audit d'accessibilité et de bonnes pratiques des pages (contraste, mode sombre, lisibilité sur téléphone). |

Ajouter une ressource : une ligne, avec son lien et à quoi elle sert **pour ce site**.
